# Meditation gong

`gong.wav` is an original, procedurally synthesized gong-like tone made for this project. No external recording, music, voice, library, or third-party request is used. It is licensed with the rest of Clean Time under AGPL-3.0.

Format: 3 seconds, mono, signed 16-bit PCM, 22,050 Hz. It combines damped sine partials at 196, 301, 427, 593 and 811 Hz with a 15 ms attack and different exponential decays. The short fade-in avoids a click. The same file plays at the start and end of meditation.


`visual-theme.js` applies only the additive device-local palette/brightness key
before CSS paints. `visual-system.css` shares the approved Welcome vocabulary
across entry/inner screens. The legacy `appearance.js` key and recovery storage
remain separate. Both new static assets are explicitly published and cached;
no new font, image, CDN or runtime dependency is introduced.
