# Assistant

Self-hosted Assistant variable font (weights 200–800), covering Hebrew and Latin.
The UI uses weights 400, 500 and 600; no remote font stylesheet or font request.

Source: https://github.com/google/fonts/tree/main/ofl/assistant
Font file: Assistant[wght].ttf (stored here as Assistant-Variable.ttf).
